# Contributing

Thanks for helping improve Cognitive Yield Monitor. The most useful contributions test whether it can distinguish stagnation from valuable repetition and productive uncertainty.

## Good contributions

- Counterexamples where the monitor warns too early.
- Loops that the monitor fails to detect.
- Cases from tutoring, emotional support, creative brainstorming, research, and decision support.
- Cross-language examples and wording improvements.
- Evaluation methods that separate false positives from missed loops.

## Principles

1. Preserve user agency; the Skill advises, it does not control.
2. Do not optimize for novelty when the user's goal is practice, emotional processing, or divergent exploration.
3. Keep claims about effectiveness proportional to evidence.
4. Protect privacy: remove personal details from submitted transcripts.
5. Explain why a proposed change improves behavior, not only style.

## Before submitting

- Run `python scripts/validate_project.py`.
- Check that evaluation cases use one of the documented states.
- Include a short rationale and note likely false-positive risks.
