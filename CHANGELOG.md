# Changelog

## 0.1.0 — Initial public draft

- Added portable English and Chinese Agent Skill instructions.
- Defined five conversation states and a conservative warning threshold.
- Added safeguards for emotional support, learning practice, creative exploration, research, and decision-making.
- Added starter evaluation cases, examples, and a rubric.
- Added a dependency-free structural validator.
- Documented limitations: the Skill is not an autonomous background monitor and is not a scientific measure of cognition.
